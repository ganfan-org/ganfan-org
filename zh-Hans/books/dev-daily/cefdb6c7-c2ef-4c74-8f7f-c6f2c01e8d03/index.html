Debian 初体验 1. 下载安装

本文编辑时间：2024年12月
随着了解的深入，发现 Debian 官网有维护很好的安装文档，包括中文版等多种语言版本。点击查看

用了很多年 Ubuntu，最近Ubuntu感觉商业化有一点点多，其实还好啦，好的东西都需要商业的支持，不可能都是为爱发电，可以理解。

这次想体验一下Debian，感觉更底层一些，Debian支持的东西，Ubuntu应该都支持，反之则不一定。

虽然我主要还是用于服务器，但始终不想加入CentOS阵营，一是因为CentOS已经停止维护了，另一个原因是大家都在用CentOS，文章资料比较多，用点儿不一样的，保持物种多样性。

这次用的是最新的稳定版本 Debian 12.8.0，发布时间应该是 2024-11-09。

Debian 介绍​

来自官方自己的介绍，首先 Debian 是一个组织，这个组织的主要产品是 Debian GNU/Linux 一种 Linux发行版，我们通常把这个操作系统叫 Debian。
https://www.debian.org/intro/index.zh-cn.html

Debian 是一个致力于自由软件开发并宣扬自由软件基金会之理念的自愿者组织。Debian 计划创建于 1993 年。Debian 一直充当着 Linux 开发的带头人。它的开发过程是开源开发模式如何工作的范例 — 即使是用于创建和维护一个完整操作系统这样复杂的任务。

Debian GNU/Linux 是一种 Linux 发行版。是第一种使用包管理系统的 Linux 发行版，它让安装和删除软件变得非常容易。

版本介绍​

版本周期，跟Ubuntu类似，LTS版本两年发布一次，支持时间为五年。每个版本都有一个代号，都取自《玩具总动员》中的一个角色，比如 Debian 12 的是 Bookworm，一个带着手电筒的虫虫。

文件类型

类型含义用途
isoISO 光盘映像文件用于创建启动盘、刻录光盘，直接进行安装
btBitTorrent 下载文件用于通过 BitTorrent 协议加速下载文件，可以用迅雷下载
jigdoJigdo 下载文件使用 Jigdo 工具下载和合并较小文件生成完整 ISO 镜像
list镜像文件或包源列表 配置镜像源帮助软件包管理器找到镜像和包

安装介质

类型含义用途
bdBlu-ray Disc 镜像适合刻录到 Blu-ray 光盘，通常包含更多的软件包
cdCompact Disc 镜像适合刻录到 CD，容量小，通常用于最小化安装。
dvdDigital Versatile Disc 镜像适合刻录到 DVD，包含更多软件包，适用于完整安装。
dlbdDownloadable Blu-ray Disc 镜像可下载的 Blu-ray 镜像，适用于离线安装。
16G16GB 镜像镜像大小为 16GB，适合在大容量存储设备上安装。

bt种子我们比较熟悉，文件很小，下载下来就是iso之类的文件。查看了一下 jidgo和list中的内容也很小，好像是个文件列表，列举要安装软件的各种deb安装包，并不能直接使用。

我们要安装系统还是要获得 iso 文件，虚拟机安装直接加载 iso 文件，物理机安装则刻录到 U 盘、光盘等来启动。

下载镜像，不一定国内的源就快，可以多试几个

再来看一下 live 版本，

Our Live CD is for everyone who wants to give Debian a try before installing it. It also includes the Calamares installer which makes it easy to install Debian from the live system. More experienced users can use the Debian installer with more options for fine-tuning, including the possibility to use an automated network installation tool.

Live 版本可以直接从 iso 文件启动体验和进行安装，类似 Ubuntu Desktop 版本。

安装过程​

可以参考 官方的安装手册，就不实际演示了。

安装时提示是否从网络下载资源进行安装，最好不要选择，直接使用 iso 文件里的安装包进行安装，否则可能下载特别慢，要漫长的等待。而且也不能取消下载和切换下载源。

我的安装环境和Debian版本

  • M4 的 MacBook Pro
  • macOS 15.2
  • VMware Fusion 13.6
  • debian-12.8.0-arm64-netinst.iso 661.7M
  • debian-12.8.0-arm64-DVD-1.iso 3.99G

使用 netinst 最小安装，安装后连 sudo 都没有，惊到了

$ sudo
bash: sudo: command not found

使用 DVD 安装一个 Gnome 桌面，应该有19个小游戏，好多。
